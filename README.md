## Overview

**Pipe SMS** is a web and android-based messaging and automation platform developed at *Damotiva Labs*.  
It enables reliable, large-scale SMS communication and integrates with backend services for account management, reporting, and data exchange. The platform is designed for research, educational, and enterprise applications where robust and programmable SMS workflows are required.

## Statement of Need

Organizations, researchers, and enterprises often require scalable SMS systems for:
- **Notifications and alerts**  
- **Two-factor authentication (2FA)**  
- **Survey distribution**  
- **Marketing and outreach**  

Existing commercial solutions are costly or closed-source. **Pipe SMS** addresses this by providing an **open, extensible, and self-hosted platform** for SMS automation.

## Features

- Web-based management interface
- Secure login and user accounts
- Bulk SMS sending
- Delivery reports and message tracking
- Integration with **PhpMyAdmin** for data management
- REST API endpoints for external system integration
- Configurable for deployment on Linux servers
